# 🌎 The Stage - MUNDIAL APP ⚽

¡Bienvenido a **MUNDIAL APP**! Una plataforma interactiva diseñada para resolver la "pesadilla logística" que representa la Copa Mundial de la FIFA 2026 en su formato continental a lo largo de Canadá, México y Estados Unidos. 


---

## 🚀 Características Principales

* **Mapa Logístico 3D Interactivo:** Un mapa estilizado de Norteamérica con relieve real (*Displacement Maps*) donde el usuario puede navegar, hacer zoom y paneo por las 16 ciudades sede. (Actualización: al final no lo agregue pero tal vez lo agregue despues, por ahora solo es un mapa 2D)
* **Información del Clima en Tiempo Real:** Integración con la API de OpenWeather para desplegar las condiciones meteorológicas actuales de cada estadio al interactuar con el mapa.
* **Branding Oficial FIFA 2026:** Interfaz adaptada con la paleta tipográfica y cromática oficial de la campaña *We Are 26*:
    * 🇲🇽 México: `#3CAC3B` (Verde Principal)
    * 🇨🇦 Canadá: `#E61D25` (Rojo Principal)
    * 🇺🇸 USA: `#2A398D` (Azul Principal)
    * ✨ Campaña: `#FC26FC` (Fucsia Vibrante para trayectorias)

---

## 🛠️ Stack Tecnológico

* **Frontend:** html,js,css
* **APIs Externas:** OpenWeatherMap API
* **Modelos 3D:** Formato optimizado `.glb` / `.gltf` (Low Poly)
